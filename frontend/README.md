# Akıllı Muhasebe - Frontend

Modernleştirilmiş frontend prototipi.

## Başlangıç
`pages/login.html` dosyasını açın.

## Sayfalar
- login.html
- register.html
- dashboard.html
- invoices.html
- invoice-new.html
- invoice-template.html
- expenses.html
- expense-new.html
- accounts.html
- reports.html
- accountant.html
- settings.html

## Yapı
- `pages/`: Sayfalar
- `components/`: Ortak sidebar/header
- `assets/css/style.css`: Tüm ortak tasarım
- `assets/js/script.js`: Ortak sayfa yükleme ve demo etkileşimleri

## Not
Bu sürüm frontend prototipidir. Gerçek backend, veritabanı, API, OCR ve GİB entegrasyonu sonraki aşamada yapılacaktır.
